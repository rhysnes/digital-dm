# Setup Wizard — question script

Use with skill **digital-dm-setup**. Ask in batches. Prefer the user’s words in files.

## Batch 1 — Frame
- Working title? (or invent later)
- Rules system? (if D&D 5e, toolkit `knowledge/5e/` + homebrew `compendium/` available)
- Solo PC or party?
- Campaign folder path / slug?

## Batch 2 — Tone & table
- Three tone words?
- Optional show palette: Dungeons and Daddies / Critical Role / NADDPOD / DnD Is For Nerds / other / none?
- Lines & veils (topics to avoid or fade-to-black)?
- Comedy: off / occasional in-universe / frequent? (Note: allowed ≠ forced.)

## Batch 3 — Setting
- Genre in their words?
- Geographic/operational scope?
- Magic or tech in one line?
- Must-include / must-exclude list?

## Batch 4 — Storyline source
Present options clearly:

**A. Existing documentation** — “We’ll use your docs/book/folder as canon.”  
**B. Completely original** — “We’ll invent a unique storyline together.”  
**C. Hybrid** — “Your lore stays; new main arc.”  
**D. Reskin** — “Named structure remounted in a new skin.”

Follow-ups:
- **A:** paths, titles, what is sacred vs adaptable  
- **B:** 2–3 premise pitches → pick → define antagonist *framework* (not a monologue dump)  
- **C:** which files/lore are locked  
- **D:** source + target genre; what must survive the reskin  

## Batch 5 — Play shape
- Structure: seasons/chapters, sandbox, mystery, crawl, shipboard…?
- Preferred narration density: terse / medium / lush (still sensible, not purple by default)?
- PC: new chargen / import sheet / stub for now?
- First session goal: chargen only / soft open / cold open?

## Confirmation card (say this back)

> **Campaign:** …  
> **System:** … · **Tone:** … · **Comedy:** …  
> **Setting:** …  
> **Storyline:** A/B/C/D — …  
> **Start:** …  
> Create files at `…`?

Proceed to scaffold only on yes.
