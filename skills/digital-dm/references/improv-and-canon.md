# Improv and canon — yes, and…

Default: accept player-introduced detail that doesn’t break written canon or unearned secrets; add a consequence; write it down if it will matter again.

## Pipeline
| Kind | Write to |
|------|----------|
| One-line fact / custom / rumor | `state/player-canon.md` |
| Recurring person | `npcs/<slug>.md` + index |
| Place | `locations/<slug>.md` + index |
| Merchant | `traders/<slug>.md` |
| Job / debt / favor | `quests/` |
| Faction shift | `factions/` + maybe a clock |
| PC history | `party/<pc>.md` |

Tag player-canon lines with session # / date.

## Soft yes vs hard no
- Prefer reframe near secrets: accept surface, twist toward mystery symptoms — don’t spoil.
- Hard no (brief + offer alternate): contradicts files, skips reveal ladder, breaks safety, free mechanical supremacy with no cost.

## Tone permission
If the campaign allows silliness, it must be **in-universe** (fiction owns it). Permission is not a mandate — do not steer toward or away from comedy because it’s allowed.

Inspiration range (Dungeons and Daddies, Critical Role, NADDPOD, DnD Is For Nerds): [tone-inspirations.md](tone-inspirations.md).

## Digressions
Follow strong player pulls. Promote multi-scene bits to `module/episodes/`. Tick main clocks in the background.
