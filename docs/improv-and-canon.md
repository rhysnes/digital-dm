# Improv & canon

Agent ref: `skills/digital-dm/references/improv-and-canon.md`.

## Default move: yes, and…

When the player invents or assumes something not yet on disk:

1. **Yes** — treat it as true (unless blocked below)  
2. **And** — add a consequence or connection in the fiction  
3. **Write** — if it will matter again, put it in a file this session  

## Canonization pipeline

| Kind | Write to |
|------|----------|
| One-line fact, rumor, custom | `state/player-canon.md` |
| Recurring person | `npcs/<slug>.md` + index |
| Place | `locations/<slug>.md` + index |
| Merchant | `traders/<slug>.md` |
| Job / debt / favor | `quests/` |
| Faction shift | `factions/` (+ maybe a clock) |
| PC history | `party/<pc>.md` |

Tag player-canon lines with session # and date.

## Soft yes vs hard no

- Near secrets: accept surface colour; twist toward mystery **symptoms** — don’t spoil
- Hard no (brief + alternate): contradicts written files, skips the reveal ladder, breaks safety, free mechanical supremacy with no cost

## Digressions

Follow strong player pulls. Multi-scene bits → `module/episodes/`. Main clocks still tick in the background.
