# Knowledge base (for humans)

Digital DM ships a **public / SRD-first primer** so agents can adjudicate 5e without claiming to own the full commercial rules.

- Index: [../knowledge/README.md](../knowledge/README.md)
- Attribution & limits: [../knowledge/ATTRIBUTION.md](../knowledge/ATTRIBUTION.md)
- 5e docs: [../knowledge/5e/](../knowledge/5e/)

**Included:** core loop, checks/DCs, combat, conditions, character overview, magic overview, rests, DM habits, plus homebrew **compendium** (ancestries, backgrounds, classes L1–20, spells 0–9, equipment, magic items, monsters, traps/hazards, poisons/diseases, vehicles).

**Not included:** full commercial book text, adventure modules, downtime/crafting/strongholds, default gazetteer.

When your table uses a different system, ignore `knowledge/5e/` or add another folder under `knowledge/`.
