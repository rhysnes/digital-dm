# Tracking guide

What to keep on disk so long campaigns stay consistent. Agent checklist: `skills/digital-dm/references/tracking-checklist.md`.

| Domain | Where | Notes |
|--------|-------|-------|
| Session snapshot | `state/campaign.md` | location, chapter, flags, next hook |
| Clocks / pressures | `state/clocks.md` | 0–N; fire consequence at max |
| Session history | `state/session-log.md` | keypoints only |
| Plot board | `state/plot-points.md` | open / hot / resolved |
| Timeline | `state/timeline.md` | in-world dates |
| Player improv | `state/player-canon.md` | accepted facts |
| Setup answers | `state/session-0-brief.md` | wizard output |
| PC sheets | `party/*.md` | stats, HP, features |
| Shared loot | `party/inventory.md` | party stash |
| Currency | `party/currency.md` (or `gold.md`) | ledger + running total |
| NPCs | `npcs/` | want, flaw, attitude, secrets |
| Locations | `locations/` | services, hooks, links |
| Factions | `factions/` | desire, pressure on PCs |
| Traders | `traders/` | stock qty, prices, restock |
| Quests | `quests/` | active / dormant / completed |
| Arcs | `module/arcs` or `seasons/` | chapter exit conditions |
| Secrets | `module/secrets.md` | never narrate raw |
| Handouts | `handouts/` | letters, map notes |

## Minimum viable NPC

1. Hook (name / look / bit)  
2. Want *today*  
3. Flaw  
4. Attitude to party  
5. Optional secret (`[DM]`)

## Minimum viable quest

Goal, giver, status, known clues, success/fail, reward.

## Currency

Define units in-campaign (gp, credits, barter marks…). Keep a ledger; don’t rely on chat memory for purse totals.

## Companions

Solo PCs with NPC companions: give companions sheets or short dossiers under `party/` or `npcs/`, and note who is “away team” in `state/campaign.md`.
