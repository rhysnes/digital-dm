# Checks and DCs

## Skills (SRD list)

Each skill maps to an ability. Proficiency (and expertise, where a feature grants it) adds proficiency bonus.

| Ability | Skills |
|---------|--------|
| Strength | Athletics |
| Dexterity | Acrobatics, Sleight of Hand, Stealth |
| Intelligence | Arcana, History, Investigation, Nature, Religion |
| Wisdom | Animal Handling, Insight, Medicine, Perception, Survival |
| Charisma | Deception, Intimidation, Performance, Persuasion |

**Tools:** same idea — proficiency with a tool lets you add proficiency bonus to checks with it (thieves’ tools, artisan tools, vehicles, etc., per SRD).

## Passive scores

Passive Perception = `10 + Perception modifier` (use for noticing without an active roll).  
Same pattern for other passives when useful (Insight, Investigation).

## Typical DC bands (DM habit, SRD-aligned)

| DC | Difficulty |
|----|------------|
| 5 | Very easy |
| 10 | Easy |
| 15 | Medium |
| 20 | Hard |
| 25 | Very hard |
| 30 | Nearly impossible |

Most adventuring tasks live at **10–20**.

## Group checks

Common public practice: majority of the group succeeds → group succeeds (useful for stealth travel, etc.). Campaign may define otherwise.

## Working together

Helper gives **advantage** to the lead character’s check when help is plausible (same check, same time).

## Tools vs skills

If both could apply, pick the one that fits the fiction; don’t stack proficiency twice unless a feature says so.
