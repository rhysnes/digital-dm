# Monster Compendium (homebrew)

Stat blocks use open 5e format. All creatures are **original** to this toolkit.  
**Proficiency** already included in listed bonuses.  
Sci-fi: reskin names (goblin → tunnel scavenger, etc.).

**Quick read:** `AC · HP · Speed · ATK · specials · CR`

## Encounter building (solo-friendly)

| Party | Adjust |
|-------|--------|
| Solo PC L1–4 | Prefer CR ≤ level; 1–2 scavengers max |
| Solo + companions | Budget as 2–3 PCs |
| Action economy | More small foes > one big foe |

Reskin freely; keep numbers.
