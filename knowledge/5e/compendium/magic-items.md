# Magic / anomalous items (homebrew)

**Attunement** = requires a short rest focus; limit **3** attuned items unless a feature says otherwise.  
Sci-fi: call them **anomalous / relic / prototype** items; same rules.

Rarity guide: **Common** shop curios · **Uncommon** mid L1–5 · **Rare** L5–10 · **Very rare** L11–16 · **Legendary** campaign prizes.
