# Magic overview

## Spell slots & preparation

- **Full casters** (wizard, cleric, etc.): slots by level; prepare or know spells per class rules.  
- **Half casters** (paladin, ranger): slower slot progression.  
- **Warlock:** fewer slots, recover on short rest (pact magic).  
- **Cantrips:** at-will, scale with character level where noted.

Always check the class’s SRD entry for “known vs prepared” and ritual casting.

## Casting in combat

Casting time usually **1 action**; some bonus action, reaction, longer.  
**Bonus-action spell rule (SRD):** if you cast a bonus-action spell, the only other spell you can cast that turn is a cantrip with casting time 1 action.

## Spell attack vs save

- Spell attack → vs AC  
- Save → target rolls listed ability vs your **spell save DC** = `8 + proficiency + spellcasting ability mod`

## Concentration

One concentration spell at a time. Damage → CON save to keep it. Incapacitated → lose it. Casting another concentration spell → replace it.

## Schools (flavor + some features)

Abjuration, Conjuration, Divination, Enchantment, Evocation, Illusion, Necromancy, Transmutation — used by wizard subclasses and some lore.

## Rituals

If a spell has the ritual tag and your class allows rituals, you can cast it with extra time without expending a slot (per class rules).

## Components

V (verbal), S (somatic), M (material). Focus or component pouch covers cheap materials; costly materials are consumed only when the text says so.

## “No magic” campaigns

If Session 0 forbids magic, treat “Clarke tech” as **features/items/devices** with explicit charges and failure modes — don’t stealth-rename fireball as magic. See campaign `rules/`.
