# Character basics (SRD-level)

For full class tables, feats beyond SRD, and subclass text: use an SRD browser or the player’s owned books. This is orientation for Digital DM.

## Building blocks

1. **Ancestry / race (SRD examples):** Human, Elf, Dwarf, Halfling, Dragonborn, Gnome, Half-Elf, Half-Orc, Tiefling — size, speed, senses, ability bumps, traits.  
2. **Class:** primary features, hit die, save proficiencies, armor/weapon training, spellcasting (if any).  
3. **Background (SRD-style):** skills, tools, language, feature, equipment flavor.  
4. **Ability scores:** often 15/14/13/12/10/8 array, point buy, or roll — campaign declares which.  
5. **Level:** proficiency bonus, class features, HP (`hit die + CON mod` each level; max at 1st).

## SRD classes (one-line jobs)

| Class | Role sketch |
|-------|-------------|
| Barbarian | Durable melee; rage |
| Bard | Face, support caster, skills |
| Cleric | Divine caster; domain playstyle |
| Druid | Nature caster; Wild Shape |
| Fighter | Reliable martial; Extra Attack path |
| Monk | Unarmored mobility; ki |
| Paladin | Half-caster smite knight |
| Ranger | Scout/hunter; half-caster |
| Rogue | Skills, sneak attack, cunning action |
| Sorcerer | Innate full caster; metamagic |
| Warlock | Pact caster; short-rest slots |
| Wizard | Prepared full caster; ritual book |

Multiclassing and multiclass prerequisites are in the SRD — enforce only if the campaign allows multiclass.

## Advancement (public)

XP thresholds or **milestone leveling** (common). Digital DM default suggestion: **milestones** tied to arc chapters unless the campaign says XP.

## Feats

Some feats appear in the SRD; many popular ones are PHB-closed. If a player wants a closed feat, either they own it and state the text, or offer an SRD/homebrew equivalent.
