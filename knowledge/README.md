## How agents should use this

1. Prefer **campaign files** over this primer when they conflict.  
2. Prefer **SRD mechanics** here over inventing incompatible rules.  
3. For spells/monsters/class features beyond summaries: use an **SRD source** (see ATTRIBUTION) or ask the player what their book says.  
4. Never paste or reconstruct substantial closed commercial text.

Campaigns using other systems: ignore `5e/` or add a sibling folder later (`knowledge/other-system/`).
