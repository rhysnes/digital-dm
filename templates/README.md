|------|-----|

| `campaign-state.md` | → `state/campaign.md` |
| `session-log.md` | → `state/session-log.md` |
| `clocks.md` | → `state/clocks.md` |

| `tone.md` | → `rules/tone.md` |
| `character.md` | PC / companion sheets under `party/` |
| `inventory.md` | Shared stash |
| `currency.md` | Purse ledger |
| `npc.md` | NPC dossiers |
| `location.md` | Places |
| `quest.md` | Individual quests |
| `faction.md` | Factions |
| `trader.md` | Merchants / stock |
| `AGENT-HANDOFF.md` | Paste block for new chats |

Fill real content from the wizard; don’t leave known fields blank.
